## 问题、解决方案与实现

| 编号 | 问题 | 已实施的解决方案 |
|---|---|---|
| F01 | 闰十一月等中文月份丢失闰月标志 | 完整解析多字月份，并保留中文日期分支的闰月信息；与数值农历入口对照验证。 |
| F02 | 非法日期被截取为合法日期 | 月日数字整体消费后执行范围校验，151 日不再被当作15日。 |
| F03 | 多钟点、冲突时段及未知时区被忽略 | 拒绝重复钟点、混合钟点格式、冲突时段和不支持的显式时区。 |
| F04 | 按整日而非转换瞬间处理夏令时 | 使用 Asia/Shanghai 的1986—1991年精确转换；拒绝跳时空档和重复时刻。新增 time_basis，独立于真太阳时开关；保留不传参数时的兼容行为并输出实际口径。 |
| F05 | 两套四柱表示互相覆盖 | 所有同时提供的扁平和嵌套四柱必须一致，否则报错。 |
| F06 | 跨盘或跨配置复用旺衰结果 | 结果携带四柱、有效默认配置键、规则身份及完整结果摘要；格局入口校验后才复用。旧精简结果需重新计算。摘要用于一致性检测，不是数字签名或领域审核。 |
| F07 | 限制动作借用无关药物或已实现药效 | 限制必须是有计划剂量和资源账的新动作；反事实绑定 action_id、药物、方法、目标、基线与剩余需求，并核验完整干预快照。原有已实现保护继续使用其原动作依赖证据，不冒充新的限制。 |
| F08 | 病图缓存遗漏上下文而返回旧结果 | 移除不完整缓存，每次从当前透干、合化和阻断条件重建；验证修改上下文与重新构造上下文结果一致。 |
| F09 | 超大整数触发 OverflowError | 数值入口共用全定义的有限数判断，超大整数、非有限浮点和布尔值均安全拒绝。 |
| F10 | 策略命中率被误当作冲突裁决通过率 | 保留命中指标，另计可执行冲突裁决；要求实际裁决案例、所遇冲突组的独立正反例，以及绑定生产配置集合的审核身份。缺失时阻断验收。 |

## 生产验收尚需的外部资料

代码整改已完成；不能据此宣称领域判断已经获得独立验证。以下资料未提供，不能用当前算法输出反向生成：

1. 经审定的调候量纲、能量映射、需求阈值及剂量限制。
2. 扶抑、承受力、通关及全局反事实的生产评估器和评估证据。
3. 特殊格局的独立判据与审定样本。
4. 固定预期的真实出生案例，以及各冲突组的独立正反例。
5. 与以上审核资料对应的生产配置集合（release_profile.config_sha256）、集合摘要和独立数据审核身份。

现有接口会明确保留证据缺口并阻断动作发布；这些外部条件未满足前，不标记为“无遗留、可生产”。

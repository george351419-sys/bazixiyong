# 日干计分与中和区扶抑降权

默认季节版新增include_day_stem=True。日干与其他天干一样按基础分、有效根档、现有合绊和月令系数计算，只计入一次；被合化时按有效五行归入相应关系。根计算读取开库和拔根后的支状态。F/K及relation_energy同步更新，gan_detail新增pos=2的日干明细。原气候构成账已包含日干，故不再重复添加。

seasonal_assessment.external_share为七字旧口径，day_stem_diagnostic.contribution为日干有效贡献，主ratio_share_f改用纳入后口径。include_day_stem=False可隔离对照；seasonal_strength=False仍整体回放季节层之前的旧行为（不加入日干）。冻结360基线保持旧配置回放，不覆盖fixture。

普通盘新门槛：P<.40身弱；.40≤P<.50中和偏弱；.50≤P<.60中和偏旺；P≥.60身旺。精确50%归中和偏旺仅为边界标签约定。从格、无根、虚旺先按结构门检查，不能仅因含日干比例升高就取消门槛。

中和偏旺/偏弱盘：扶抑移到格局与调候之后，候选五行支持权重由1降为0.5；扶抑反向意见记录fuyi_caution，不作为普通明确反对来自动排除候选。实际融合仍比较精确点名、结构角色、交集和条件，不能理解为完全忽略扶抑。普通身旺/身弱保留原季节排序。

四申庚金：季节层七字F352.8 K201.6，日干庚60×强根1×金旺1.3=78，最终F430.8 K201.6，主占比68.1214%，身旺。原63.6364%仅保留对照。

测试新增40/50/60边界、日干只计一次、F/K关系账一致、气候账不重复添加、中和扶抑软化。旧层合同测试明确固定include_day_stem=False，生产入口与新规则另测。全回归通过。迁移JSON比较在同一新门槛下，仅切换日干纳入，不能称为领域准确率。

40/50/60为用户确定的新工程规则；极弱20%、承受25%、从格85%暂保留，仍未获得独立领域标注校准。降低扶抑的权重0.5是初版工程实现，不是假称存在通用命理兑换率。

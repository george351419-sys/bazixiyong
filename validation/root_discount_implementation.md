# 统一天干根气折扣：第一阶段

默认symmetric_root_discount=True；所有非日主天干统一使用强根1、中气0.8、微根0.6、无根0.2。False保留旧版“克泄耗不折扣”的回放。基础分、合绊、地支藏干、得令规则不变；不加入无根得生或季节增益。

每个天干debug记录root_factor，F/K与relation_energy同源更新。气候能量账仍是原始构成账，不与扶抑有效作用账混同。该差异是有意保留，不将原始五行占比冒充有效生扶占比。

四申案例：F288，K180，份额61.5%，仍身旺；甲贡献12。旧版K228，份额55.8%。

360盘迁移详见root_discount_migration.json，31盘旺衰标签变化。原fixture不刷新，冻结回归明确使用legacy配置；新规则有独立针对性测试。参数敏感性结果不能作为独立准确率。

从格资格、根状态继续用原有结构门槛；比例门槛暂保留，未伪造重新标定结果。31盘中跨从格与普通格的迁移必须视为规则模型变化，不是领域已验证。极弱0.20及承受0.25仍为工程阈值，新口径下应结合独立样本继续审核；未凭既有模型反向生成正确答案。这些阈值和后续“无根有源”“月令系数”不属于本次已完成的校准。

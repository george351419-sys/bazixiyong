# 扶抑与融合细节修复（direction_v7）

对应前次复核 `fuyi_policy_detail_review.md`。本轮修复实现与输出语义，不调整用户已确定的计分参数。

## 已落实的修改

| 问题 | 修改后行为 |
| --- | --- |
| 40%、50%、60%端点随浮点尺度变标签 | 使用交叉乘积与机器精度容错；不按展示百分比四舍五入判定，85%/15%从格范围也共用比较方法 |
| 合化日干对照公式总把日干归生扶 | 按实际有效五行关系决定日干贡献进入F还是K，与主账口径一致 |
| 春秋扶抑内部偏好晚于调候比较 | 正偏印、比劫完整偏好嵌入扶抑所在季节优先级块；冬夏仍先调候，中和区仍降低扶抑优先级 |
| 潜在救应被当成原局无条件支持 | 保留为候选，标记待透或待运及重新核验条件；不作为当前强格局共识 |
| 入选喜用同时涉及未解格局病却无说明 | 为具体字及五行记录剩余病量、证据和作用条件，并在CLI与网页展示；不机械删除具有双重作用的字 |
| 五行并列被固定顺序掩盖 | 天干、五行统一输出名次、并列组、是否选中、截断并列及原因；仍最多六字、三五行 |
| 中和区原始扶抑文案过硬 | 原始扶抑也标记soft，将反向偏好与最终忌神区分 |
| 最近参数分散、复用结果规则身份不完整 | 新增fuyi_policy共享参数和版本；旺衰复用身份绑定政策版本 |

## 参数保持

日干计入主账；普通旺衰40%/50%/60%，从强/从弱候选85%/15%并保留结构门槛；天干根系数1/.8/.6/.2；旺相休囚死1.30/1.15/1/.85/.70；土月土1.30，其余元素采用既定季节混合。中和区扶抑权重、极弱与承受探测等既有工程参数没有借本轮修复重新调值。

## 适用边界

当前方向融合是有条件的排序政策；候选方向、原局已有效力、未来增量药效继续分别记录。冲突说明不等于证明该字增量安全。5%探测、20%/25%等经验参数尚无独立领域标定，严格药效与相容性评估的pending状态仍独立保留；本轮没有把方向结果伪装成已完成的严格评估。

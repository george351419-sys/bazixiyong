# 格局模块本轮优化验收

日期：2026-11-06。

本轮将已有规则固定为可重复执行的回归，修正节气交界的排盘衔接和页面说明；不另增格局取用规则。

## 实现

- `tests/fixtures/calendar_360.json`：固定种子1606，360个1900—2030年的公历时间，记录四柱及格名、类别、成破、清浊、明暗。外格开关交替启用。保存完整默认配置，配置改变时先明确提示审核迁移。
- `tests/test_calendar_regression.py`：复算四柱并比较行为基线，验证治疗分配、剩余容量、证据引用和JSON输出的一致性；另外验证2026年12个节的前1秒、交界、后1秒共36个时点，以及两种晚子时约定下共10个样本。
- `bazi_core/paipan.py`：计算节后天数改用精确节气月支，避免交节当天、交节时刻之前错误匹配新月而返回空值。
- `web/index.html`、`web/app.js`：明确节后天数用途；逐病展示实际治疗分配；暗格说明使用真实取格依据。
- `tools/run_regression.py`：统一回归命令，任何检查失败即退出非零状态。

## 联动变更记录

初次生成基线后，同一工作区的旺衰从格专项发生更新（`metadata.py`和`wangshuai.py`的修改时间分别为21:50、21:51，晚于19:56生成的基线），现有《从格专项_口径对照与改造方案.md》记录了相应定稿。当前实现对5个启用外格的样本产生迁移：

| 日期 | 原基线 | 当前结果 |
|---|---|---|
| 1931-06-08 09:00 | 食神格 | 从儿格 |
| 1949-04-16 15:00 | 食神格 | 从儿格 |
| 1948-10-18 22:00 | 从杀格 | 食神格（旺衰为假从弱） |
| 2010-06-01 14:00 | 正财格 | 从财格 |
| 2030-06-19 10:00 | 食神格 | 从杀格 |

本轮保留最新旺衰实现，将5例前后完整字段及当前旺衰标签存入`calendar-baseline-migration.json`，基线按当前配置重建。关闭外格的180例未产生迁移。此记录是联动行为变化，不是另外批准命理规则的结论。

## 验证结果

统一命令：`python3 tools/run_regression.py`。

- 格局：20用例、199断言，失败0。
- 格局修订及历法回归：78个unittest方法通过，其中历法方法包含360日期、36交节时点、10子时样本。
- 旺衰：35用例、88断言，失败0；固定种子2000盘不变量检查，失败0。
- 调候：18用例通过；网页JavaScript语法检查通过。

桌面Chrome人工可视核对：

1. `丁午 癸酉 甲子 癸子`：月癸首选、时癸辅佐的逐柱区分，以及实际救应说明。
2. `甲午 戊辰 辛丑 丁丑`：条件取用、未解决病与待透分别展示。
3. `乙亥 庚辰 戊午 壬午`：透干失效降暗格的真实依据，以及时壬首选。

最终页面截图：`browser-final.png`。未进行移动端专项验收。

# 季节交集方向融合 v1

本轮按用户授权提供默认可运行的方向兜底。严格仲裁原样保留；新增 direction_fusion，仅对事实有效、普通结构、严格仲裁尚未完成的盘启用。真从、假从、化格等特殊结构和无效事实不套普通季节规则。

## 取舍

1. 扶抑候选取现有 favored；格局取已选透干和潜在藏干救应候选；调候只取通用及完整条件已触发项，不纳入未知条件。
2. 按五行合并丙和火等包含关系。优先两维及以上交集，交集内按支持维度数排序。
3. 同等支持按冬夏：调候、格局、扶抑；春秋：格局、扶抑、调候。具体天干同样先比较跨维度支持，再按季节优先级。无交集也按此顺序给首选。
4. 扶抑忌向与候选相交时记录显式方向冲突；不因另一维度未提到某行就认定反对。主选可按优先级保留，但标明限制；反向的其他候选不进入辅助列表。
5. 输出 heuristic，而非 pending；保留原始仲裁 pending 和未验证动作状态。启发式方向不发布剂量、实际药效或行动处方。

## 参数与样本

运行 `python3 tools/evaluate_direction_fusion.py`：360盘冻结行为案例，非独立领域金标准。火/水占比下四分位为0.0953/0.0968，上十分位为0.3518/0.3811；生扶占比下四分位0.245。

- 季节极端指标：冬季火占比<0.10且水>=0.35；夏季水<0.10且火>=0.35。只是寒热代理，不涵盖全部燥湿。季节次序已用于排序，极端指标提供复核提示，不另加未经验证的排序权重。
- 承受代理：标准化增加总量0.05的候选五行，生扶占比变为 `(F_share + 0.05 if 生扶 else F_share) / 1.05`。生扶方向标为 supported；其他方向若试探后低于0.25，标为 limited，否则 tolerable_proxy。仅报告方向敏感性，不是重排命盘，也不伪装成真实承受力验证。
- 冲突数值：显式反对维度数 /（反对数+支持数）。当前仅扶抑忌向有自动反对证据，不能误称完整全局相容性评分。
- 修复候选评分：已选透干1.0，潜在藏干0.5，没有候选0。是候选可见性等级，不是修复概率；不改写原局格局成败。

这些是初版工程参数，描述统计仅帮助选择尺度，不能证明参数最优或命理准确。修复和承受代理目前只作解释字段，不能作为完整路线通过证据。

## 本盘

庚午 戊寅 己酉 壬申：格局候选丁丙、扶抑火土、调候丙。火获三维支持，丙获格局和调候精确支持；方向首用丙，辅助土。癸水条件“一派火”未确认，不列固定次用。格局原始“真破格”保留，不因方向选择丙就声称原局已修复。

## 结果与边界

360盘有322盘得到普通方向兜底；其他38盘依原特殊结构或条件规则处理。严格仲裁和生产发布验收不因新增方向层自动通过。仍缺全局干支反事实、完整燥湿模型和独立领域样本；本轮没有用构造证据把它们标记已完成。
